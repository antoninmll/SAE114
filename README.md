# Site Web Trilogie Cars

Site web dédié à la trilogie Cars de Pixar - Projet BUT Réseaux et Télécommunications.

## Présentation

Projet réalisé dans le cadre de la SAE 14 en première année de BUT Réseaux et Télécommunications. L'objectif était de concevoir un site web respectant les standards du W3C et les normes d'accessibilité, tout en appliquant les compétences acquises en développement web.
Le site explore la trilogie Cars de Pixar à travers des pages dédiées à chaque film, enrichies de contenus détaillés. Le projet met en pratique les technologies HTML5 et CSS3 avec un design responsive et des animations modernes.
